## [0.1.0] - YYYY-MM-DD

### Added
- Initial release of the Tron Legacy global theme for KDE Plasma 6.
- Color scheme, Plasma style, Aurorae window decorations, and wallpaper.
- Look-and-Feel package with animated splash screen and lock screen.
- SDDM login-manager theme.
- Konsole, Kate, Vim, Neovim and VS Code color schemes.
- Tron Container Monitor Plasma 6 widget with systemd timer backend.
- `install.sh` installer script.
