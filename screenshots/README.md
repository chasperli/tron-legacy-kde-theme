# Screenshots

Place your screenshots in this folder. They are referenced by `README.md` and
needed for the KDE Store / GitHub release.

## Required images

| Filename | Content | Why |
|----------|---------|-----|
| `preview-desktop.png` | Wide desktop shot (panel, wallpaper, open window) | README hero image |
| `desktop.png` | Clean desktop overview | README screenshot table |
| `lockscreen.png` | Lock screen with clock and password field | README screenshot table |
| `widget.png` | Container Monitor widget showing real container data | README + Store highlight |
| `konsole.png` | Terminal with the color scheme | Optional but nice |
| `kate.png` or `vscode.png` | Editor with syntax highlighting | Optional |

## Tips for good screenshots

- **Resolution:** At least 1920×1080. The KDE Store crops to 16:9.
- **No personal info:** Hide usernames, file paths, or emails before shooting.
- **Active looking:** Have a few windows open (Konsole, Kate, file manager) so the theme shows its full potential.
- **Widget:** Make the Container Monitor visible on the desktop or panel with actual running containers.

## Store thumbnail (optional but recommended)

For the KDE Store you also need a **square or 16:9 thumbnail** (store.kde.org uses it as the cover image). You can reuse `preview-desktop.png` for this.
